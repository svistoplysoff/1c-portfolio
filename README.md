## Мои проекты:

### ⚙️ [«Управление ИТ фирмой» — учётная система](https://github.com/svistoplysoff/1c-portfolio)

Учётная система ИТ-компании: закупки и продажи, деньги, расчёты с контрагентами, цены и скидки, зарплата, бизнес-процессы с задачами, управленческий учёт и отчётность.

- Проведение реализации по **двум контурам учёта** (регистр накопления + регистр бухгалтерии, двойная запись) с **контролем отрицательных остатков**: при нехватке товара документ не проводится, пользователь получает понятное сообщение — исключена отгрузка сверх остатка.

- **Расчёт себестоимости** списания средневзвешенным методом (пропорционально остаткам) одновременно в оперативном и бухгалтерском контурах учёта.

- **Зарплата:** план видов расчёта «Начисления» (оклад, премия процентом, фиксированная премия, больничный, отпуск), регистр расчёта с периодами действия, документы-расчётчики, функциональная опция «Вести расчёт зарплаты».

- **Бизнес-процесс «Поручение»** с маршрутом и автоматической адресацией задач исполнителям (сотрудник или роль), задачи «Задачи мне» на рабочем столе.

- **Управленческая отчётность** на СКД по данным двойной записи: оборотно-сальдовая ведомость, взаиморасчёты с контрагентами, движение товаров, доходы и расходы.

**Технологии:** 1С:Предприятие 8.3.27, язык запросов 1С, регистры накопления/сведений/бухгалтерии/расчёта, план счетов с видами субконто, СКД, бизнес-процессы и задачи, общие модули, функциональные опции.

**Состав:** 5 справочников · 9 документов · 10 регистров · 4 отчёта · 1 бизнес-процесс · 6 подсистем

### 📋 [«Автоматизация документооборота» — договоры и акты](https://github.com/svistoplysoff/1c-portfolio)

Компактная конфигурация учёта договоров и актов выполненных работ ИТ-специалиста.

- Документ «Акт выполненных работ»: **часы × ставка** с автопересчётом итоговой суммы на форме, формирование акта из **HTML-шаблона**.

- Серверная генерация печатной формы: подстановка данных в макет, **склонение ФИО по падежам с определением рода**, **сумма прописью** (до миллиардов), период прописью; вывод в окно предпросмотра.

- Клиент-серверное взаимодействие: `НаСервереБезКонтекста` для чтения связанных данных, запись/чтение временного файла UTF-8 на сервере с его удалением, `НаКлиенте`-обработчики.

**Технологии:** 1С:Предприятие 8.3.27, управляемые формы, клиент-серверное взаимодействие, HTML-шаблоны, сумма прописью, склонение ФИО.

**Состав:** 3 справочника · 1 документ · 2 HTML-шаблона · 2 подсистемы

## Как открыть проекты

Выгрузки выполнены в иерархический XML (ConfigDumpInfo, формат 2.20). Загрузка в базу:

1. Установить платформу 1С:Предприятие **8.3.27**.

2. Создать пустую информационную базу.

3. В Конфигураторе: **Конфигурация → Загрузить конфигурацию из файлов…** → выбрать папку нужного проекта.

4. Обновить конфигурацию базы данных (**F7**).
